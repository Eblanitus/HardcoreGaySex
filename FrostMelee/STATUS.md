# Статусы оружия FrostMelee

Обновлено: 28 октября 2026 года. Этот файл — сводка текущей реализации;
[plans.md](plans.md) отвечает за прогрессию и будущие решения.

## Как читать статусы

- **Готово по механике** — переработка считается законченной по текущим решениям.
  Это не обещание отсутствия багов и не подтверждение сетевого теста.
- **Реализовано, нужна проверка/доводка** — собственная механика есть в коде,
  но нельзя объявлять оружие законченным.
- **Заготовка / не сделано** — общие приёмы или каркас есть, собственной
  законченной переработки нет.
- **Черновик** — прототип существует, но не соответствует окончательному дизайну.
- **План** — намерение, не реализованное оружие.

Игровое подтверждение указывается отдельно. Старое подтверждение конкретной
механики не заменяет регрессию после объединения веток и сетевых изменений.

## Текущие оружия

| Оружие | Статус | Что есть | Что ещё нужно / проверка |
|---|---|---|---|
| Ледяной клинок / Ice Blade | Готово по механике | Общие приёмы, полировка, ледяные эффекты | В прежних планах принят как готовый; регрессия после общих изменений ещё не зафиксирована |
| Frostbrand | Готово по механике | Холодное пламя, ограниченный запас языков, возврат огоньков, снятие горения тычком | В проектных записях есть подтверждение владельца (`flame-28`); объединённая версия требует регрессии |
| Замороженное копьё / Ice Sickle | Готово по механике | Взмах, тычки, выставленное копьё, бросок, Frost, иней и замороженный вид | Ранее отмечено готовым; новые маски и синхронизацию Frost проверить в игре |
| Амарок | Готово по механике | Управляемый полёт, наводка, круг, лёд, двойник | Новая owner-authoritative сетевая реализация внесена, игровой сетевой тест не подтверждён |
| Ледяной бумеранг | Готово по механике | Лёгкие броски, размах, заряжаемый тяжёлый бросок, вихрь и скольжение | В прежних планах подтверждён владельцем (`boomer-18`); баланс по ощущениям и общая регрессия остаются |
| Меч-леденец / Candy Cane Sword | Реализовано, нужна проверка/доводка | Общие приёмы, приманивание брошенным мечом, расход/возврат сладости, серый вид | Отдельное подтверждение завершённости и полного игрового теста не зафиксировано |
| Меч из ёлки / Christmas Tree Sword | **Заготовка — оружие не сделано** | Реестр общих приёмов и золотисто-хвойная дуга; ванильные снаряды заменены дугой | Собственная механика не определена и не реализована. Владелец явно не считает подключение движка готовым оружием |
| Айсберг | Реализовано, нужна проверка/доводка | Крафт, тяжёлый меч, глыбы, раскол, Frostbite, взаимодействия тычка/встречи и глазурь | Нужен игровой тест; финальная графика меча и глыб не утверждена. Предложенный ассистентом спрайт отклонён |
| Ледниковый цеп | Черновик | Гибрид thrown/launched, инерция, бросок и лежащая голова | Старые `flail-1/2`, не финальная схема. Новые кнопки и лассо из `HardcoreMelee/flails.md` — пока план |
| Северный полюс | Заготовка — переработка не сделана | Пустой `SpearPlayer`, крючок `NorthPoleGlobalItem`; ванильное поведение сохранено | Нужны механики и реализация копейного движка |

## Запланировано, но не реализовано

| Оружие | Зафиксировано | Пока не определено |
|---|---|---|
| Йо-йо из меха Флинкса | Дохардмод; в прежнем плане — мех Флинкса и северная древесина | Рецепт в числах, реализация и проверка |
| Нога йети | Поздняя ветка йо-йо, план улучшения флинксового через новый материал с Йети | Реализация оружия и нового дропа |
| Снежный ком | Цеп дохардмода | Получение, характеристики, точный тир и механика; нарастание при качении — только предложение |
| Полярная звезда | Цеп хардмода; основа крафта — Упавшие звёзды + Ледяное ядро (`FallenStar` + `FrostCore`) | Дополнительные материалы, количества, станция, точный тир и механика |

«Снежный ком → Полярная звезда» не утверждён как рецепт улучшения.
Заменять ли ими старый Ледниковый цеп — не решено. Его текущий дроп не менялся.
[Цеп-фонарь](../HardcoreMelee/идеи/Цеп-фонарь.md) — отдельная идея, не обязательная
часть ледяной линейки и не обещание реализации.

## Что не утверждено для меча из ёлки

Обсуждавшиеся метки-игрушки на врагах, их разбивание тычками и выпуск звезды
при попадании остриём не приняты владельцем. Не включать их в описание текущего
оружия, план реализации или критерии готовности без отдельного решения.

## Общее состояние проверки

- Код и Python-тесты масок доступны; это не результат сборки мода.
- В окружении агента нет установленного .NET SDK/tModLoader: компиляция
  объединённой версии и игровые сценарии здесь не выполнены.
- Полная сетевая проверка, жизненный цикл брошенных предметов и регрессии
  перечислены в [MAINTENANCE.md](../MAINTENANCE.md).
- Для всей серии: ReaperMelee и WoodSwordsOverhaul — отдельные проекты.
  Исправления FrostMelee не означают, что они перенесены в соседние моды.
