# Шаг 3: разбор движка (ItemCheck, Shoot, жизненный цикл снаряда)

Источник: патч tModLoader `Terraria/Player.cs` (stable).

## Когда вызывается стрельба

- **ItemCheck_Shoot** вызывается при условии:
  - `sItem.shoot > 0 && flag2`
  - где **flag2 = itemAnimation > 0 && ItemTimeIsZero && flag** (и ещё проверки)
  - **ItemTimeIsZero** = `itemTime == 0` (свойство в патче).

То есть выстрел происходит в кадр, когда **itemTime уже 0** и **itemAnimation ещё > 0**. Момент выстрела привязан к обнулению itemTime, а не к концу анимации.

## Как обновляются таймеры

- В патче: **itemTime** каждый кадр уменьшается (`itemTime--` при `itemTime > 0`).
- Комментарий TML: «itemTime идёт от itemTimeMax до 1, затем может сброситься; 0 = предмет не используется».
- Есть правки про синхронизацию **itemAnimation** и **itemTime** для autoReuse («TML is motivated to bring the itemAnimation and itemTime counters to parity, fixing desync bugs with autoReuse items»).

## Уничтожение снарядов в Player

- В патче **Kill()** по проектам вызывается явно только в контексте **граплингов** (SingleGrappleHook) — при смене крюка убивают старый.
- Для копий в этом патче **нет** явного вызова Kill() по нашему снаряду. То есть старый снаряд копья умирает **не из ItemCheck**, а по своей логике — когда у него **timeLeft** доходит до 0 в цикле обновления снарядов.

## Вывод по порядку кадров

1. Снаряд жив, пока у него **timeLeft > 0**; в конце кадра время снарядов уменьшается.
2. **ItemCheck_Shoot** вызывается в кадр, когда у игрока **itemTime == 0** и **itemAnimation > 0** — в этот момент создаётся **новый** снаряд.
3. Значит, «пустой кадр» возможен, если:
   - в одном кадре сначала обновляются снаряды → старый копейный снаряд по timeLeft умирает;
   - затем в том же кадре (или в следующем) выполняется ItemCheck игрока и вызывается ItemCheck_Shoot.
   Порядок систем (снаряды до/после игрока) в Terraria нужно смотреть в основном цикле обновления (Update), не в этом патче.

## Что досмотреть для точного ответа

- В **Terraria/Main.cs** или цикле Update: порядок вызовов `UpdateProjectiles()` и `Player.ItemCheck()` / обновления игрока.
- В **Terraria/Projectile.cs** (ванильный): как aiStyle 19 (копьё) меняет **timeLeft** — привязка к itemAnimation/itemTime или только к своему счётчику.

После этого можно будет точно сказать, на каком кадре старый снаряд исчезает относительно кадра вызова ItemCheck_Shoot и нужен ли продление timeLeft (шаг 1) или правка в другом месте.
