> описанная в них коллизия обычной крутки отменена этим уточнением.

**`20261029-flail-controller-v8`**, версия мода **0.1.1**.

Реализация внесена по [аудиту v7](FLAIL_ROTATION_AUDIT_2026-10-29.md).
Это не заявление, что все игровые дефекты устранены: **полная сборка C#,
загрузка мода и dedicated-server прогон здесь не выполнены**.

## Управление

- ЛКМ — сквозной прямой бросок, удержание повторяет после возврата.
- ПКМ — крутка. Отпускание возвращает голову, не бросает её автоматически.
- ПКМ + один новый клик ЛКМ — вся атака лассо:
  **Cast → Approach → Wrap → Yank → Return**.
- После запуска лассо обе кнопки можно отпустить. Второй клик не нужен и не
  наносит дополнительный урон. Наведение на UI не отменяет уже начатую атаку.
- Смена слота/экземпляра оружия, смерть, CC, потеря цели, нехватка длины или
  настоящее препятствие отменяют атаку. Сброса головы на землю больше нет.

## Что исправлено относительно аудита

| Проблема v7 | Реализация v8 |
|---|---|
| 26–35 тиков на оборот | В свободном пространстве базовый оборот 12 тиков; полный ком — 16 (−25% скорости). Угол интегрируется по шагам, не пересчитывается от текущей массы |
| Орбита поднята на 8 px и почти не проходит снизу | Базовые полуоси ExampleMod 30√2, 24√2 и 12√2; центр MountedCenter + gfxOffY. У пола размер головы учитывается отдельно |
| Радиальное сжатие головы у стен | ClearOrbitPosition удалён. Путь головы проверяется от предыдущей точки короткими шагами; запрещённый угловой шаг не засчитывается |
| Игрок навсегда смотрит в сторону запуска | При крутке facing обновляется по прицелу. Поворот тела вне крутки следует голове; itemRotation поправляется по фактической стороне головы |
| Стартовый запрет урона зависит от массы/скорости | Отдельный SpinTicks в реальных тиках; первые 12 без урона. Отдельно Phase и RampTicks |
| Невыполненный общий разгон | ×0.6 → ×1.4 за 90 тиков движущейся крутки. Отпускание/остановка вращения сбрасывают разгон |
| Невыполненное правило дистанционного урона | ×1.2 до 96 px, линейно до ×0.5 на конце 320px цепи |
| Одна голова прекращает полёт на NPC | Оба цепа пробивают NPC; локальная перезарядка 10 тиков в броске, 20 в крутке. Смена стадии не обнуляет иммунитет NPC |
| Быстрая голова пропускает маленькую цель между кадрами | Попадание проверяется по всей ломаной движения головы за кадр, через расширение AABB цели на размер головы |
| Движение и рисунок лассо используют разные эллипсы | LoopPoint задаёт один контур для движения, рисунка и бюджета цепи; параметры контура передаются клиентам |
| Подход к орбите обнуляет прогресс обмотки | Approach — отдельная стадия; прогресс Wrap начинается только после достижения входной точки |
| Один плохой отсчёт сбрасывает полный обход | Прогресс растёт только на реально разрешённых шагах по контуру. Краткая блокировка приостанавливает его, а не обнуляет; после 12 блокировок попытка отменяется |
| Каждый клиент независимо угадывает захват | Только сервер выполняет переходы, TryBind и TryYank. Снимок содержит стадию/угол, winding, контур, таймеры и причину отмены |
| Масса каждые 6 тиков перезаписывает состояние головы | Отдельный пакет ModPlayer для массы; Snowball больше не ставит projectile.netUpdate и не пишет свою массу в ExtraAI |
| Рывок требует нового клика | Полный разрешённый оборот немедленно начинает серверный Yank |
| Урон/раскол до реального стягивания | TryYank только начинает перемещение. Урон и расход кома — однократно при успешном завершении. Заблокированное стягивание не расходует ком |
| Срыв непонятен, а голова уже исчезла | Владелец получает отдельное сообщение причины; она видна ещё 3 секунды после исчезновения головы |

### Осознанные отличия от ваниллы

- Сохраняется правило **«урон только физической головой»**. Полный ванильный
  55px эллипс не добавлен. Swept-AABB устраняет пропуск головы между кадрами,
  но не превращает пустое пространство внутри орбиты в наносящую урон область.
- ЛКМ/ПКМ остаются нашими отдельными приёмами. Ванильные channel/release-to-throw,
  Drop и множитель ×2 не возвращены.
- Возврат безопасный, без урона и сквозь тайлы.
- Полная ванильная орбита используется там, где есть место. У пола/платформы
  нижняя часть подстраивается под голову 28–44 px; у стены угол может остановиться.
  Это не разрешение бить сквозь стену или сжимать радиус радиальным лучом.
- Угловая скорость обычного Spin не масштабируется скоростью атак (как у эталона).
  Скорость броска/возврата/облёта всё ещё учитывает её. Масса замедляет все приёмы.
- Полярная звезда получает общую базу, но **Созвездие не реализовано** этой работой.

## Физика и урон

`ShouldUpdatePosition = false`: все стадии используют явное перемещение, чтобы
не было второго автоматического шага движка после нашего AI. MoveHead разбивает
движение на отрезки не длиннее 4 px, учитывает TileCollision и проверяет solid.
Крутка и обмотка дополнительно дробят угол, поэтому попадание не проверяется
по длинной хорде через пустой центр круга. Проверка опоры у ног учитывает
платформы, а не только SolidCollision. Начальная постановка головы у игрока
отделена от попаданий первыми 12 тиками запрета урона Spin.

Лассо выбирает NPC **на уже разрешённом тайлами пути**, не на длинном
предполагаемом луче за стеной. Весь полный контур резервируется из 320 px цепи.
У крупного NPC/большого кома рабочая дистанция лассо может быть меньше — длина
тратится на реальную орбиту, а не на меньший нарисованный эллипс из v7.

NPC перемещается короткими шагами. Пол может обрезать Y, пока остаётся свободный
X. Блокировка движения не даёт бесплатный удар. Достижение зоны 40 px у игрока
или завершение 18 тиков успешного переноса даёт один удар/эффект кома. При
таймауте без движения, смене оружия или препятствии расхода кома нет.

**Обычный контактный урон** остаётся в штатном projectile-пайплайне Terraria
на клиенте-владельце, с ModifyHitNPC/ModifyHitPlayer и локальным иммунитетом.
**Стадия, движение, захват, перемещение NPC, удар рывка и ресурс** принадлежат
серверу/SP. Это не заявленная защита от произвольного модифицированного клиента;
штатный SyncProjectile движка отдельно не заменялся античит-протоколом.

## Сеть

Игровые протоколы v7/v8 несовместимы: **обновить и пересобрать мод на сервере и
всех клиентах**, не смешивать версии. Сохранённые предметы не переименованы;
снаряды после перезагрузки мода создаются заново.

- Клиент не создаёт голову и не задаёт ai/позицию своими mod-пакетами.
  Передаёт состояние кнопок, отдельный фронт клика, слот, тип предмета, единичный
  прицел и номер сообщения. Сервер использует whoAmI соединения, проверяет
  длину пакета, конечность/диапазон прицела, монотонность номера, выбранный
  слот/предмет и физическую возможность атаки.
- Ввод передаётся при изменении и раз в 6 тиков при выбранном цепе. Если сервер
  60 тиков не видит ввод, удержание прекращается; уже запущенная автоматическая
  атака не превращается в удерживаемый канал.
- Голова создаётся сервером/SP; повторный запуск проверяет все активные головы
  игрока, а не только локальный кэш индекса. Одновременно одна голова на оба цепа.
- Снимок головы — раз в 6 тиков, при лассо раз в 3 и при смене стадии; клиенты
  предсказывают движение между снимками, но не принимают решения о захвате.
- Масса передаётся отдельным серверным пакетом и через SyncPlayer для позднего
  входа. Раскол и причина отмены имеют отдельные сообщения, чтобы не потеряться
  вместе с удалением снаряда. Оригинальный 6-байтовый Frost-пакет копья сохранён.
- Ввод идёт через сервер: отклик первого запуска и коррекции при высоком ping
  требуется отдельно проверить в игре. Клиентская предсказанная генерация головы
  намеренно не возвращалась, чтобы не получить двух авторов состояния.

## Проверки в среде агента

- 23 Python-теста: контракты исходников, размеры пакетов, сохранение правил
  рецептов/массы и независимые математические модели периода/зазора/урона.
- Tree-sitter разобрал 70 C# файлов FrostMelee без синтаксических ошибок.
- Обе RU/EN HJSON локализации разобраны Python hjson.
- Генератор масок с `--check`: маски соответствуют PNG.
- `git diff --check`: без ошибок.

**Ни один из этих пунктов не является C# type-check/build или игровым тестом.**
.NET SDK в среде не установлен. Попытка скачать release tModLoader с GitHub
завершилась ошибкой доступа к release-assets; полноценная сборка не выполнена.
Предыдущие узкие source-тесты заменены контрактами нового контроллера, а не
сохранены как ложное доказательство поведения удалённого кода.
