# Fly skin (64×64, classic / Steve model)

`fly_skin.png` — готовый скин. Классическая модель (4 px руки), PNG 64×64, RGBA.
Подходит для загрузки на minecraft.net → Profile → Skin, а также для TLauncher / лаунчеров,
которые принимают classic-скины.

## Что взято из исходного скина
| Исходник | Стало |
|---|---|
| серебристо-серые волосы | серебристый пушок на голове, груди и бёдрах |
| зелёные глаза | фасеточные глаза мухи |
| чёрная одежда + фиолетовый галстук | хитиновые пластины + фиолетовая полоса/усики |

## Что добавлено
- фасеточные глаза на слое шляпы (выступают за силуэт головы);
- усики (фиолетовые) на темени;
- три простых глазка (ocelli) на макушке;
- сложенные полупрозрачные крылья на слое куртки (видны со спины);
- сегментированное брюшко с полосами;
- бледные коготки на кистях и ступнях.

## Файлы
- `fly_skin.png` — скин (64×64)
- `fly_3d_all.png` — рендер с 6 ракурсов
- `fly_preview.png` — плоская развёртка (front / back / right / left)
- `make_fly_skin.py` — генератор скина (пиксель-арт задан строками)
- `preview.py` — плоская развёртка
- `render3d.py` — мини-рендер модели в 3D
- `source_skin.png` — исходный скин

## Перегенерация
```bash
python3 skins/make_fly_skin.py
python3 skins/preview.py skins/fly_skin.png
python3 skins/render3d.py skins/fly_skin.png skins/fly_3d.png
```
