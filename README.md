# HardcoreMelee — серия модов Terraria / tModLoader

Репозиторий содержит несколько отдельных игровых проектов и общие дизайн-документы.
Цель серии — сделать ближний бой выгоднее дистанционной стрельбы оружием мили.

| Каталог | Назначение |
|---|---|
| [FrostMelee](FrostMelee/README.md) | Ледяное и праздничное оружие; основная текущая работа |
| `ReaperMelee` | Отдельная переработка Death Sickle |
| `WoodSwordsOverhaul` | Деревянные мечи/палки и заточки |
| `HardcoreMelee` | Философия, планы классов оружия и идеи; не единый готовый мод, объединяющий остальные |
| `ReferenceSprites` | Графические референсы; часть PNG используется генератором масок |

## Границы готовности

Наличие класса, текстуры или общих приёмов не означает законченного оружия.
Меч из ёлки и Северный полюс — общие базы приёмов без уникальной механики;
новые цепы — заготовки; Полярная звезда заменяет старый Ледниковый цеп,
его отдельный контроллер и дроп удалены.
Подтверждённые владельцем этапы отделены от ещё не проверенной общей/сетевой
регрессии. Реализованный код не выдаётся за результат компиляции или теста.

Исправления FrostMelee не переносятся в ReaperMelee и WoodSwordsOverhaul
автоматически. В этой документационной ревизии соседним модам не присваивались
новые статусы готовности без отдельной проверки.
