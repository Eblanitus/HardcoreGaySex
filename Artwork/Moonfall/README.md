# Moonfall — спрайт оружия в стиле Terraria (2026)

Оригинальный предмет: **Moonfall** — одноручный меч поздней игры, «кованый из лунного
света»: фиолетово-стальной клинок с раскалённой досиня кромкой, золотая гарда-крестовина,
тёмная оплёточная рукоять с золотыми кольцами и золотое навершие с лунным камнем.

Спрайт нарисован с нуля пиксель за пикселем (не сгенерирован и не отфильтрован),
в размерах и по правилам ванильных иконок предметов.

## Файлы

| Файл | Что это |
|---|---|
| `Moonfall_item.png` | 52 × 58 px, RGBA, прозрачный фон — готовый предмет (можно класть в `Content/Items/` мода) |
| `Moonfall_item@2x.png` | 104 × 116 px — тот же спрайт ×2, для превью в 200 % UI |
| `Moonfall_preview.png` | ×8 на тёмном фоне, для просмотра |
| `Moonfall_sheet.png` | презентационный лист: реальные размеры, слот инвентаря, палитра, разбор стиля |
| `make_moonfall.py` | генератор спрайта (вся геометрия, палитра и правила шейдинга — в коде) |
| `make_sheet.py` | генератор презентационного листа |

Пересобрать всё:

```bash
python3 make_moonfall.py
python3 -c "from PIL import Image; im=Image.open('Moonfall_item.png'); \
im.resize((im.width*2, im.height*2), Image.NEAREST).save('Moonfall_item@2x.png')"
python3 make_sheet.py
```

Требуется только `Pillow`.

## Почему это читается как Terraria

Правила взяты из того, как устроены ванильные иконки оружия:

1. **Один размер пикселя.** Никакого сглаживания, никаких фильтров, никаких «полупикселей»:
   иконка сразу рисуется в финальном разрешении, как `Frostbrand` (52 × 58) или
   `Death Sickle` (70 × 64).
2. **Обводка в 1 px, но не чёрная.** Каждая деталь обведена затемнённым оттенком
   собственного цвета (клинок — тёмно-фиолетовым, гарда — тёмно-коричневым). Чистый
   `#000000` в ванили не используется.
3. **Свет сверху-слева.** Поэтому у режущей кромки всегда горит белая линия — даже если
   формально она в тени, — а обух остаётся холодным и тёмным.
4. **Пять ступеней на материал.** `shadow → body → light → specular` плюс обводка.
   Никаких градиентов: только резкие ступени.
5. **Плоские планы, а не труба.** Клинок собран из кромки, фаски, плоскости и затенённой
   плоскости, а не из круглого профиля — иначе металл выглядит пластиком.
6. **Остриё дорисовано руками.** Последние три пикселя — тонкая стальная игла, иначе
   кончик читается квадратным.
7. **Куски металла выложены построчно под 45°.** Гарда, рукоять и навершие — это
   диагональные полосы, у которых рисунок шейдинга сдвигается ровно на 1 px за строку:
   так блокирует форму живой пиксель-артист, и так же выглядят ванильные мечи.
8. **Никаких оторванных частиц.** Иконки предметов в Terraria чистые — блёстки и искры
   живут в снарядах и эффектах, а не в спрайте предмета.

## Заметки по внедрению в мод

- Текстура предмета кладётся как обычно: `Content/Items/Moonfall.png` (имя файла = имя
  класса предмета).
- Спрайт нарисован по диагонали «снизу-слева → вверх-вправо», как ванильные мечи: при
  `Item.useStyle = ItemUseStyleID.Swing` и стандартном `ItemLoader` он корректно
  поворачивается вокруг рукояти.
- Если понадобится другой масштаб иконки для UI — используйте `@2x`-версию, но в самой
  игре предмет должен ссылаться на 1×.
