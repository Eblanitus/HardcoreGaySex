# PureMana — мод на класс мага

Статус: концепт, 10 ноября 2026 года. Ничего не реализовано, кода нет,
сборка и игровой прогон не проводились.

`PureMana` — рабочее название, не финальное. Записанного имени мода на GitHub
не найдено: проверены файлы и все ветки репозитория, issue, PR и вики.

Отдельный мод серии HardcoreMelee: переделывает класс мага так же, как
[philosophy.md](../philosophy.md) переделывает ближний бой. Доктрина ближнего
боя («сближение выгоднее») на мага не распространяется: у класса своя задача —
сделать ману прокачиваемой характеристикой вместо ограничения.

## Решения владельца (10.11.2026)

| Вопрос | Решение |
|---|---|
| Имя мода | `PureMana`, рабочее, не финальное |
| Имя предмета-настройки | Не фиксируем: «эффект снаряда», «настройка». «Руна» — только разговорное слово, не имя |
| Мана на нуле | Стрельба без эффектов, без штрафа к урону |
| Что качает максимум маны | Скорость снаряда, силу эффектов, скорострельность; не урон |
| Источник максимума маны | Зелье даёт временный бафф; остальные ванильные источники маны остаются |
| Зелье маны | Переделывается в зелье максимальной маны |
| Выбор эффекта | Аксессуар кладёт настройку в слот боеприпасов; настроек может быть несколько |
| Цена | Одиночный эффект почти бесплатен, сочетание эффектов растёт сверхлинейно |
| Сила эффекта | Тир аксессуара × максимум маны |
| Запуск | Только задержка первого выстрела после простоя |
| Броня | Влияет через +максимум маны, отдельных бонусов нет |
| Набор эффектов | Пять: ускорение, курсор, автонаводка, рикошет, двойной/тройной снаряд |

Числа и конкретные формулы ниже нигде не выдаются за сбалансированные
значения: где их нет, стоит отсылка к [не-решено.md](не-решено.md).
